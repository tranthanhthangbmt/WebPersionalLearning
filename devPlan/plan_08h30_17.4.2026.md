# 🏗️ MASTER BLUEPRINT: Kiến Trúc All-in-One JSON & UGC Marketplace

Cấu trúc lại toàn bộ nền tảng học tập PKT Bio-Tutor theo mô hình **"Local-first / File-first"**, nơi toàn bộ dữ liệu cấu trúc môn học, tài nguyên học tập và trạng thái cá nhân (tiến trình, XP) được gói gọn trong **MỘT FILE JSON DUY NHẤT**.

Chiến lược này biến mỗi cây tri thức thành một "băng game" di động. Người dùng có thể dễ dàng tải xuống, chia sẻ công khai (như Canva, Quizlet) và học tập độc lập mà không cần một hệ cơ sở dữ liệu server-side cồng kềnh.

## 🗺️ Kiến Trúc "Nguyên khối" của File JSON Mới

Giải pháp cho vấn đề: *Làm thế nào để hệ thống chia sẻ mượt mà và đồng bộ tiến độ học mà không cần hệ quản trị dữ liệu phức tạp?*

Mọi tệp tin JSON (ví dụ: `TMDT101_thanh_v1.json`) giờ đây sẽ mang định dạng như sau:

```json
{
  "metadata": {
    "version": "2.0",
    "tree_id": "uuid-xyz",
    "title": "Thương mại điện tử",
    "author": "Giảng viên A",
    "is_public_template": false
  },
  "student_state": {
    "user_id": "thanh",
    "global_xp": 1250,
    "last_accessed": "2026-04-17T15:30:00",
    "current_level": "Chiến binh",
    "bio_battery_level": 0.85
  },
  "nodes": {
    "c1.1": {
      "type": "micro",
      "label": "Khái niệm chung về TMĐT",
      "content": "Nội dung bài học...",
      "resources": [
        {
          "type": "video",
          "title": "Youtube: Bài giảng C1",
          "url": "https://youtube.com/watch?v=..."
        },
        {
          "type": "pdf",
          "title": "Slide (Google Drive)",
          "url": "https://drive.google.com/file/d/..."
        }
      ],
      "progress": {
        "mastery": 0.95,
        "is_completed": true,
        "last_interaction": "2026-04-17T15:00:00",
        "ebbinghaus_memory_decay": 0.8
      }
    }
  },
  "edges": [
     {"source": "m1", "target": "c1.1", "relation": "contains"}
  ]
}
```
*Ghi chú: Nếu file nằm trên "Kho Chung", phần `student_state` và `nodes[*].progress` sẽ bị xóa sạch hoặc ẩn đi. Người dùng bấm "Thêm vào thư viện số của tôi" thì hệ thống sẽ copy file json đó về tài khoản của mình và cho phép bắt đầu ghi nhận thao tác.*

## 🛠️ Proposed Changes (Kế hoạch Triển khai)

### Giai đoạn 1: Base Core & Parser Engine (Lõi dữ liệu)

#### [MODIFY] `data_manager.py` (hoặc tạo `json_engine.py`)
- Xây dựng lại Trình nạp dữ liệu (Parser Loader). Thay đổi để đọc định dạng JSON mới.
- Xây dựng 2 luồng đọc:
  - `load_public_catalog()`: Nạp danh sách các cây `is_public_template = true` từ mục `/DB/public_trees/`.
  - `load_user_library(user_id)`: Nạp các cây thuộc quyền sở hữu cá nhân từ thư mục `/user_data/username/trees/`.
- Xây dựng hàm `save_course_state(json_data, user_id)` để ghi đè toàn bộ sự thay đổi (làm quiz, nhận XP) xuống lại File JSON vật lý.

#### [NEW] Kiến trúc Liên kết Tài Nguyên (NotebookLM style)
- Phân tích Node JSON sẽ chấp nhận Array `resources`.
- Các tài nguyên như YouTube, PDF, Audio Cloud sẽ không bao giờ được tải lên máy chủ. Hệ thống chỉ nhúng iframe hoặc pop-up modal qua các URL này khi User click vào node trong cây đồ thị 3D.

---

### Giai đoạn 2: User Interface Redesign (Đại tu Entry Point)

#### [MODIFY] `main.py`
- **Entry Point Đảo ngược**: Mặc định tab mở ra đầu tiên sẽ KHÔNG PHẢI là "Hành trình". Nó sẽ là tab **"Thư viện Cây của Tôi"** (My Library).
- Giao diện My Library: Hiển thị các ô thẻ Card vuông vắn (như Canva, Quizlet) cho các khoá học JSON đã lưu. Các thẻ này hiển thị kèm thanh Tiến Độ (Progress Bar) bóc tách từ File JSON cá nhân.
- Khi Click vào Card môn học ➡️ Load cây 3D và giao diện "Hành trình" tương ứng.

#### [NEW] `library_page.py` & `marketplace_page.py`
- **UGC Marketplace (Kho Chung)**: 
  - Giao diện Lưới (Grid Network) nơi người dùng chia sẻ cây tri thức định dạng chuẩn.
  - Phím "Clone to My Library". Module này sẽ thực hiện lệnh Copy Tệp JSON từ Master Template ➡️ Bơm Data Rỗng ➡️ Chép vào thư mục User.

---

### Giai đoạn 3: Tích hợp Multimedia Player (Kết nối Resource)

#### [MODIFY] `ai_video_player.py` / `flashcard_page.py`
- Gắn logic tương tác 3D: Khi nhấp đúp vào Node trên Đồ thị 3D, thanh Menu Node bật lên sẽ không chỉ có "Câu hỏi", mà sẽ có danh sách "Nguồn tham khảo".
- Tùy vào định dạng URL trong thuộc tính JSON (`type: video/pdf/audio`), hệ thống sẽ gọi Component UI tương ứng cho nổi lên trên Layout:
  1. Nếu ID là Youtube ➡️ Render iframe Youtube nhúng trực tiếp.
  2. Nếu Google Drive PDF ➡️ Mở GView Render.
  3. Nếu URL MP3 ➡️ Gọi Media Player nhỏ gọn để vừa nghe podcast vừa khám phá map.
