## 🎯 Tìm thấy lỗi rồi!

Nhìn vào cột `PORTS`:

```
0.0.0.0:8080->8081/tcp
```

**Port mapping sai!** Bạn đã map host port **8080** → container port 8081. Nhưng Nginx (và lệnh bạn nói) đang kỳ vọng port **8081**.

Nghĩa là bạn đã chạy `-p 8080:8081` thay vì `-p 8081:8081`.

### Fix ngay — chạy trên AWS:

```bash
# 1. Dừng container cũ
docker stop myapp
docker rm -f myapp

# 2. Chạy lại với PORT ĐÚNG: 8081:8081
docker run -d -p 8081:8081 --name myapp --restart unless-stopped treeknowledge-app


# 3. Đợi 10 giây rồi test
sleep 10
curl http://localhost:8081/api/health
```

Nếu `curl` trả về `{"status":"healthy"...}` → app hoạt động.

Sau đó kiểm tra thêm Nginx có proxy đúng port 8081 không:

```bash
cat /etc/nginx/sites-enabled/default
```

Gửi output cho tôi nếu vẫn còn lỗi 502 sau khi fix port.
